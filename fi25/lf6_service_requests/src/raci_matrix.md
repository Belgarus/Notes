# RACI-Matrix

> Lernfeld 6: Serviceanfragen bearbeiten, Leistungskontrolle am 02.11.2026 (Übung U2)

## Was ist die RACI-Matrix?

Eine Tabelle, die festlegt, **wer bei welcher Aufgabe welche Rolle hat**. Sie schafft Klarheit über Zuständigkeiten und vermeidet, dass Aufgaben doppelt oder gar nicht erledigt werden.

Die Buchstaben stammen aus dem Englischen:

| Buchstabe | Englisch | Bedeutung | Kern |
|---|---|---|---|
| **R** | **Responsible** | **Verantwortlich für die Durchführung** (Durchführungsverantwortung) | Wer **tatsächlich macht** es? |
| **A** | **Accountable** | **Genehmigungs- und rechenschaftspflichtig**, aus **Kostensicht** (Kosten- bzw. Gesamtverantwortung); **genehmigt** die nötigen Ressourcen | Wer **entscheidet und haftet**? |
| **C** | **Consulted** | **Fachkompetenz, Expertise** oder sonstiger Beitrag ist erforderlich (**Beraterrolle**), aber **nicht verantwortlich** für den Prozess | Wer **wird gefragt**? |
| **I** | **Informed** | Muss über **Status und/oder Ergebnisse** **informiert** werden (Informationsrecht) | Wer **wird informiert**? |

> **Merkhilfe:** R macht, A entscheidet und haftet, C berät, I wird informiert.

## Aufbau der Matrix

- **Links** stehen die **Aufgabenbereiche** bzw. konkreten **Aufgaben**
- In der **Kopfzeile** stehen die **Rollen** der Beteiligten
- In den **Zellen** steht der Buchstabe R, A, C oder I (oder die Zelle bleibt leer)

## Regeln und Tipps (prüfungsrelevant)

| Regel | Formulierung |
|---|---|
| **Mindestens ein R** | In **jeder Zeile** sollte **mindestens ein Verantwortlicher (R)** benannt werden |
| **Genau ein A** | In **jeder Zeile** sollte **nur ein Accountable (A)** benannt werden |
| **A und R trennen** | Es sollte **vermieden** werden, **einer Rolle/Person A und R** zu geben (**Konfliktpotenzial**) |
| **Leere Rollen prüfen** | Hat eine Rolle (Spalte) **überhaupt keine Zuordnung**, sollte man überlegen, ob sie **überhaupt eingebunden** werden muss |

## Beispiel: Autoreparatur

| Aufgabe | Servicemanager | Meister | Geselle | Lagerist | Geschäftsführer |
|---|:---:|:---:|:---:|:---:|:---:|
| Termin mit Kunden vereinbaren | **R** | C | | | **A** |
| Fahrzeug untersuchen | | **R** | I | I | **A** |
| Ersatzteile beschaffen | | **A** | | **R** | |
| Reparatur durchführen | I | **A** | **R** | | |
| Rechnung erstellen | **R** | | C | | **A** |

**Lesebeispiel:** Bei "Reparatur durchführen" macht der **Geselle** die Arbeit (R), der **Meister** trägt die Verantwortung und genehmigt (A), und der **Servicemanager** wird nur **informiert** (I).

### Typische Prüfungsfragen zur Matrix

- **Zeile ohne R?** Dann macht niemand die Aufgabe, ein R ergänzen.
- **Zeile mit zwei A?** Unklare Gesamtverantwortung, auf ein A reduzieren.
- **Person mit A und R in derselben Zeile?** Konfliktpotenzial, Rollen trennen.
- **Spalte komplett leer?** Prüfen, ob die Rolle überhaupt gebraucht wird.

## Spickzettel

- **R** = Responsible: führt **durch**
- **A** = Accountable: **genehmigt, trägt Kosten- und Gesamtverantwortung**
- **C** = Consulted: **berät** mit Fachwissen, nicht verantwortlich
- **I** = Informed: **wird informiert** über Status/Ergebnisse
- **Pro Zeile:** mindestens ein **R**, genau ein **A**, A und R **nicht bei derselben Rolle**
- **Leere Spalte:** Rolle überdenken
