# Beispielaufgabe

### Angebot und Nachfrage:
Angebot und Nachfrage von Erdbeerkuchen

```
| Preis (€) | Nachfrage | Angebot |
| --------- | --------- | ------- |
| 0         | 12        | 0       |
| 1         | 11        | 2       |
| 2         | 9         | 4       |
| 3         | 7         | 7       |
| 4         | 2         | 8       |
| 5         | 0         | 10      |
```
---

**a)**
```
Preis (€)
5 |        \  / 
4 |         X  
3 |       /  \
2 |     /     \
1 |   /        \
0 | /           \   
   -------------------
    0 2 4 6 8 10  Menge
```
**Legende:**  
/ = Angebot (steigend)  
\ = Nachfrage (fallend)  
Schnittpunkt bei Menge 7, Preis 3 €  

---

**B) Gleichgewicht**

- Menge: 7 Kuchen  
- Preis: 3 €  
- Umsatz: 7 * 3 € = 21 €
---

**C) Preisfixierung**

- Preis 1 € → Nachfrage > Angebot → Nachfrage-Überschuss
- Preis 4 € → Angebot > Nachfrage → Angebots-Überschuss
